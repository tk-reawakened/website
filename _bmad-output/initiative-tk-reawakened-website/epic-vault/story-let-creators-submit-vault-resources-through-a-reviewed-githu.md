# Let creators submit Vault resources through a reviewed GitHub PR

## Description

Reuse the game catalogue’s intake and PR workflow with Vault-specific checks for licence, author credit, compatibility, installation and the download or source link.

## Acceptance Criteria

Verify: A creator submits an extension or pack through the guided intake. A moderator verifies it on a supported build, previews and publishes the entry by PR, and can update or remove it without changing the rest of the catalogue.
