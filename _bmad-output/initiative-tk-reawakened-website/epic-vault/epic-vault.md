# The Vault for extensions, templates and asset packs

Website priority 3 · Asset and game sharing

A beginner can find a compatible resource, learn how to use it and share a resource of their own through moderated catalogue publishing.

## Done when

1. A beginner finds one item from the home page or a matching guide, sees the supported release, credit, licence and installation steps, and uses it in an original example project.
2. A creator submits an extension or pack through the guided intake. A moderator verifies it on a supported build, previews and publishes the entry by PR, and can update or remove it without changing the rest of the catalogue.

## Dependencies

- [Epic 29](../epic-community/epic-community.md) supplies the community topic links and first feedback round (29.2, 29.3).
- [Epic 30](../epic-game-submissions/epic-game-submissions.md) supplies the reviewed catalogue PR workflow (30.2), for Vault submissions.

## Scope

Start with links to approved releases and downloads. Verify the usage instructions against the current release. The Games epic supplies the shared review and publishing workflow.
