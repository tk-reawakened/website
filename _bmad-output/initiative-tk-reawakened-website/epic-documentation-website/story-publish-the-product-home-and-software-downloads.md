# Publish the product home and software downloads

## Description

A visitor understands what TK Reawakened does, can find the right official release for creating or playing, and can reach the first guide from Home, Create or Docs. Build the static site shell and release-links handoff here.

## Acceptance Criteria

Verify: On a small screen and with a keyboard, a visitor finds requirements, the correct shipped build or editor, release notes and matching docs. The site distinguishes preview and stable releases and gives a useful path when a build is unavailable.
