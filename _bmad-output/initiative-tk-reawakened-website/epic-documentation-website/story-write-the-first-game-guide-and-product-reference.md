# Write the first-game guide and product reference

## Description

A beginner can make a small game and a returning creator can import, debug, test, package or share with the released tools. Cover install and editor workflows, RPGCode, troubleshooting and developer contributions in the appropriate guides.

## Acceptance Criteria

Verify: The first-game guide has a reproducible original example. Reference examples and commands match the shipped product and normative spec, use the project’s help-text style, and link to the released source of truth.
