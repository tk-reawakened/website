# Community for new RPG creators

Website priority 2 · Community

A first-time RPG maker can meet other beginners, ask for help, show progress and receive feedback they can use on their next build.

## Done when

1. A guest can read help and playtest topics, a new member can sign in and post, and a moderator can receive a report and act on it. Record venue ownership and how to keep or export useful public history.
2. A visitor reaches a specific live topic from a site page, replies after sign-in, and can follow a link back. Direct links still work if any optional embed or activity feed is unavailable.
3. Run one prompt, make sure participants receive a response, and publish a credited recap with a route back to the guide. Record whether makers posted, returned or acted on feedback.

## Dependencies

- [Epic 17](../epic-documentation-website/epic-documentation-website.md) supplies the published product and docs and the release walkthrough (17.5).

## Scope

Start with GitHub Discussions and choose the repository or organization home with its moderators. Provide beginner-friendly categories and direct discussion links. Test GitHub sign-in with a beginner and investigate exporting discussion history. Evaluate giscus for inline replies and add embeds or a feed where they help a visitor reach a useful conversation.
