# Connect the website to durable community topics

## Description

Add a clear Community route from the site and a reusable topic-link pattern for tutorials, prompts and future game pages. Show selected activity on the home page when there is something current to share.

## Acceptance Criteria

Verify: A visitor reaches a specific live topic from a site page, replies after sign-in, and can follow a link back. Direct links still work if any optional embed or activity feed is unavailable.
