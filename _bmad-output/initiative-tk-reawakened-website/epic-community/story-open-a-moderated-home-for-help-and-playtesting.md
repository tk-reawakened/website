# Open a moderated home for help and playtesting

## Description

Set up GitHub Discussions as the initial community venue and identify a person responsible for moderation. Choose its repository or organization home. Give beginners clear ways to ask questions, introduce projects and request feedback, plus conduct and reporting information.

## Acceptance Criteria

Verify: A guest can read help and playtest topics, a beginner can sign in with GitHub and post, and a moderator can receive a report and act on it. Test the sign-in and posting journey with a beginner. Record venue ownership and investigate how to export useful public history.
