# Run a first-game prompt and feedback round

## Description

Invite beginners who just finished the guide to share a small piece of work, try someone else’s, and offer feedback. Assign a host and use a prompt sized for the tools available.

## Acceptance Criteria

Verify: Run one prompt, make sure participants receive a response, and publish a credited recap with a route back to the guide. Record whether makers posted, returned or acted on feedback.
