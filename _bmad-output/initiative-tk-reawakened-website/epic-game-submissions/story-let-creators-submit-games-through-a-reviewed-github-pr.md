# Let creators submit games through a reviewed GitHub PR

## Description

Provide beginner-friendly intake for a new game or recovery lead. Collect a description, screenshots, build or source link, credit and permission, and the discussion link where applicable. Have a moderator verify the candidate and open a catalogue PR using the shared review and publish workflow.

## Acceptance Criteria

Verify: A creator submits a playable WIP without editing repository files. A moderator can request changes, verify browser play and listing rights, and preview the static entry. A reviewed merge publishes the metadata and its links. Recovery leads stay in review until rights and availability are verified.
