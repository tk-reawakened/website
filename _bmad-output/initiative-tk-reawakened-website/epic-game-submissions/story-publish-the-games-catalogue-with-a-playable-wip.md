# Publish the Games catalogue with a playable WIP

## Description

Create catalogue records and browse pages for preserved games, new releases and Work in Progress. Seed one authored browser-playable game and link to approved corpus entries where their listing rights and availability are known.

## Acceptance Criteria

Verify: A player can distinguish preserved, released and in-progress games. A featured WIP has credited screenshots, a browser-playable build, a specific feedback request and a direct link to its Community topic. The topic links back to the same stable game URL.
