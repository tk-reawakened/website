# TK Reawakened Website

This repository serves the official website for TK Reawakened, an independent open-source project that plays and imports legacy RPG Toolkit games. The [product repository](https://github.com/tk-reawakened/rpgtoolkit-reawakened) owns the engine, editor, release artifacts, and normative engine and format specifications.

## Web implementation

Use [Modern Web Guidance](https://developer.chrome.com/docs/modern-web-guidance) during website implementation and review regardless of the framework, host, or forum provider. To install the published skill for Codex in this checkout, run:

```sh
gh skill install GoogleChrome/modern-web-guidance skills/modern-web-guidance --agent codex --scope project
```

Use the guidance relevant to the change and verify that the supported browser and accessibility paths work. Use the product's actual release and specifications to verify technical copy, examples, and supported game imports.

## Planning and provenance

Track work on the [organization roadmap](https://github.com/orgs/tk-reawakened/projects/3) and retain existing GitHub issue references when moving BMAD planning files. [Epic 17](https://github.com/tk-reawakened/rpgtoolkit-reawakened/issues/1362) and its [hosting spike](https://github.com/tk-reawakened/rpgtoolkit-reawakened/issues/2709) currently live in the product repository.

Record the source, rights and credit for every game, screenshot, asset pack or archive item published on the site. Follow the product project's [clean-room and licence rules](https://github.com/tk-reawakened/rpgtoolkit-reawakened/blob/main/docs/guardrails.md) where the site publishes product material or bundles dependencies and assets.
