# TK Reawakened Website

This repository is the home for the TK Reawakened website at `tk-reawakened.com`. The site will help people get the software, learn to make RPGs, find games and creator resources, and meet the community behind them.

- [TK Reawakened engine and editor](https://github.com/tk-reawakened/rpgtoolkit-reawakened)
- [Website and documentation epic](https://github.com/tk-reawakened/rpgtoolkit-reawakened/issues/1362)
- [Hosting and publishing research](https://github.com/tk-reawakened/rpgtoolkit-reawakened/issues/2709)

The website stack and production host are open while the hosting spike compares costs and tests catalogue publishing on the leading candidates.
